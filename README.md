# NekoAI 安卓客户端

这里是 NekoAI 安卓 App 的**版本存档**，也是**反馈问题**和**提功能建议**的地方。

App 的源代码不在这里，这个仓库只放安装包和更新日志。

## 下载

每个版本的安装包都在 [Releases](../../releases) 里，附有更新日志。最新的在最上面。

- 安装包是签了名的正式版。覆盖安装就能升级，聊天记录和设置都在服务器上，不会丢。
- 第一次安装时，系统可能提示「来自未知来源」，按提示允许即可。

## 反馈问题（Bug）

在 [Issues](../../issues/new/choose) 里选「问题反馈」，请尽量写清楚：

- App 版本：在「我的 → 设置 → 关于 → 版本」里能看到
- 手机型号和 Android 版本
- 做了什么、期望看到什么、实际看到了什么
- 截图或录屏（如果有）

## 功能建议（Feature Request）

在 [Issues](../../issues/new/choose) 里选「功能建议」，说说你想要什么、想用它解决什么问题。

## 注意

Issue 是**公开**的，任何人都能看到。请**不要**贴出：

- 密码、验证码、兑换码
- QQ 号、邮箱、手机号
- 聊天记录里的隐私内容

截图前先把这些打码。涉及账号、封禁、余额的问题，请在 App 里的「账号状态」申诉，或者到官网 [neko.中国](https://neko.中国) 联系我们。
